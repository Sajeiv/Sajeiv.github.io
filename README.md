# sajeivravichandran.com

Personal site of Sajeiv Ravichandran, software and AI developer in Toronto.

**Live:** https://sajeivravichandran.com

## Built with

- Plain HTML, CSS and JavaScript, with no framework or build step
- Space Grotesk, Inter and JetBrains Mono from Google Fonts
- Hosted on GitHub Pages

## Notes

- Single-file site: the profile photo and company logos are embedded in `index.html`
- Light and dark themes follow the visitor's system setting
- Accessible: semantic landmarks, skip link, keyboard focus states, reduced-motion support
- SEO: title and meta description, canonical URL, Open Graph and Twitter cards, JSON-LD (`Person`, `WebSite`, `ProfilePage`), `sitemap.xml` and `robots.txt`
